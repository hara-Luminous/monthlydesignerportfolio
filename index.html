新しい作品の追加、既存作品の編集、公開・非公開、並び替えができます。

Supabaseの初期設定が必要です

config.js に Project URL と anon key を設定してください。詳しい手順は同梱の README.md にあります。

設定前でも公開画面には同梱の3作品を表示します。管理画面の共通保存はSupabase設定後に有効になります。
